# Tanda Doloreña

Aplicación móvil desarrollada en Flutter para la gestión y administración de tandas.
* Características
Registro de participantes.
Gestión de pagos.
Seguimiento de tandas activas.
Interfaz sencilla y amigable.
Compatible con Android, Web y Windows.
